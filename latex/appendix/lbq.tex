\chapter{Language Background Questionnaire}\label{app-lbq}

The language background questionnaire was included in the C-test validation study, the direct object relative clause (ORC) study, and the subject relative clause (SRC) study. Participants comprised English native speakers (ENSs), L1-Korean L2ers of English (KLEs), and L1-Mandarin L2ers of English (MLEs). Required languages in the ``Languages You Speak'' section consisted of English and (for L2ers) the participant's native language.\vspace{5pt}

\textbf{Basic Information}
\begin{enumerate}
\item Age 
\item Gender \{Male, Female, Nonbinary\} 
\item Place where you grew up \{State/Province, Country\} 
\item Place where you live now 
\item Highest level of education completed \{High School Diploma, Undergraduate Degree, Graduate Degree, Other\}
\end{enumerate}\vspace{10pt}

\textbf{Places Where You Have Lived}\\\vspace{5pt}

\textbf{Country 1 (Required):}
\begin{enumerate}
\item Name of country
\item Age when you moved to this country \{Not Applicable, Born in this country, 1, 2, 3, etc.\} 
\item Total number of years spent living in this country 
\item Age when you moved away (if applicable)
\end{enumerate}\vspace{10pt}

\textbf{Country 2 (If Applicable):}
\begin{enumerate}
\item Name of country
\item Age when you moved to this country \{Not Applicable, Born in this country, 1, 2, 3, etc.\}
\item Total number of years spent living in this country
\item Age when you moved away (if applicable)
\end{enumerate}\vspace{10pt}

\textbf{Country 3 (If Applicable):}
\begin{enumerate}
\item Name of country
\item Age when you moved to this country \{Not Applicable, Born in this country, 1, 2, 3, etc.\}
\item Total number of years spent living in this country
\item Age when you moved away (if applicable)
\end{enumerate}\vspace{10pt}

If you have lived in any additional countries, tell us about them here\vspace{10pt}

\textbf{Languages You Speak}\\\vspace{5pt}

\textbf{English (Required):} 
\begin{enumerate}
\item Proficiency level \{Beginner, Low Intermediate, High Intermediate, Advanced, Near-Native, Native Speaker\}
\item Age when you started learning this language \{From Birth, 1, 2, 3, etc.\}
\item Did your primary caregivers speak this language to you when you were a child? \{Yes, No\}
\item Percentage of total weekly listening/speaking/reading/writing time spent using this language
\item Number of years spent studying this language as a second or foreign language (if applicable)
\item Have you taken any advanced courses on English syntax (600-level or above?) \{Yes, No\}
\end{enumerate}\vspace{10pt}

\textbf{Language 2 (If Applicable):}
\begin{enumerate}
\item Name of language
\item Proficiency level \{Beginner, Low Intermediate, High Intermediate, Advanced, Near-Native, Native Speaker\}
\item Age when you started learning this language \{From Birth, 1, 2, 3, etc.\}
\item Did your primary caregivers speak this language to you when you were a child? \{Yes, No\}
\item Percentage of total weekly listening/speaking/reading/writing time spent using this language
\item Number of years spent studying this language as a second or foreign language (if applicable)
\end{enumerate}\vspace{10pt}

\textbf{Language 3 (If Applicable):}
\begin{enumerate}
\item Name of language
\item Proficiency level \{Beginner, Low Intermediate, High Intermediate, Advanced, Near-Native, Native Speaker\}
\item Age when you started learning this language \{From Birth, 1, 2, 3, etc.\}
\item Did your primary caregivers speak this language to you when you were a child? \{Yes, No\}
\item Percentage of total weekly listening/speaking/reading/writing time spent using this language
\item Number of years spent studying this language as a second or foreign language (if applicable)
\end{enumerate}\vspace{10pt}

If you speak any additional languages, tell us about them here
