# dissertation

This repository contains the materials, data, and analysis files for my dissertation project in the Department of Second Language Studies at the University of Hawaiʻi at Mānoa. My committee members were Bonnie D. Schwartz (Chairperson), Kamil Deen, Li ‘Julie’ Jiang, William O’Grady, and Amy Schafer.

## Analysis Folder

The “analysis” folder contains the data and analysis files. The main data file, “data.csv”, is in the “data” subfolder. See “analysis.R” for the R code I used to generate the plots and conduct the principal analyses.

## LaTeX Folder

The “latex” folder contains the files I used to write the dissertation in LaTeX. The “main.tex” file draws on files in the other folders (including the “analysis”, “image”, and “materials” folders) to compile the dissertation. See the output file “main.pdf” for the full text of the dissertation.

## Materials Folder

The “materials” folder contains the experiments I built for the project using jsPsych. Download the folder and open the html files in your internet browser to experience the experiments more or less how the participants did.
